📊 Vendor Performance Analysis using Python & Power BI
📌 Overview
This project evaluates vendor performance through sales data analysis. It covers the complete workflow:

Data ingestion and cleaning

Exploratory Data Analysis (EDA)

Automated summary generation

Interactive dashboard development in Power BI

Final reporting with actionable insights

🛠️ Tech Stack
Languages: Python (Pandas, Matplotlib, Seaborn)

Tools: Jupyter Notebook, Power BI, Excel

Other: Automated PDF Reporting

💡 Key Features
Automated ingestion & cleaning of vendor sales data

Comprehensive EDA to uncover trends and patterns

Python scripts for generating vendor summary reports

Interactive Power BI dashboard with rich visualizations

Professional PDF report with finalized insights

🚀 How to Run
Clone the repository

Run notebooks in /notebooks for EDA and analysis

Execute get_vendor_summary.py to generate vendor summary

Open vendor_performance.pbix in Power BI for dashboard view

Review the final PDF report in /reports

📈 Outputs
Vendor performance summary (CSV)

Interactive Power BI dashboard (PBIX)

Final insights report (PDF)
